# 驗證紀錄

日期：2026-11-10（Asia/Taipei）。

## 本輪已執行

- 以 USB esptool 辨識為 ESP32-S3 revision v0.2。
- 讀出原 Flash 的前 2 MB，MD5 傳輸驗證通過；備份 SHA-256 `95a9715019c04e0aab9bcc8b51ce063c1ccdc782dae93ddc57fbdbc8347983ed`。備份含原 bootloader、分割表、NVS、OTA metadata 與本輪會覆寫的 app 區域，不是整片 16 MB 備份。
- 核對原有分割表為 NVS 0x9000、app0 0x10000/0x640000、app1 0x650000/0x640000；OTA metadata 選擇 app0。
- 實際燒錄僅寫入 app0 `0x10000`；沒有寫入 bootloader、分割表、OTA metadata 或原檔案系統。esptool 寫入後雜湊檢查通過。
- ESP32 序列埠診斷回報：station `7210`、touch `0x15`（CST816）、PSRAM `8385991` bytes、portal `1`。
- 從實機取得 320 × 170 RGB888 畫面緩衝區，核對繁中設定頁、熱點名稱、隨機密碼與設定 IP。緩衝區能驗證程式實際排版；實體 LCD 是否亮起仍需使用者確認。
- PlatformIO espressif32 6.5.0 / Arduino ESP32 2.0.14 交叉編譯通過。最終二進位雜湊見 `firmware/manifest.json`。
- 板上序列指令切換兩個方向並返回原方向，均收到狀態回報；這不等同實際觸控驗證。
- C++ 資料模型測試通過：UTC／臺灣時間、兩方向分流、缺動態不顯示準點、晚點保留、斷線／過期狀態、取消／停駛、站號／日期過濾、跨午夜晚點列車。
- 臺鐵官方車站基本資料下載並檢查，246 個唯一站號、包含礁溪 7210 及前導零站號。設定頁 HTML 已組裝核對站名選項及預設選取。
- 從 TDX 官方 OpenAPI 核對使用路徑、回應包裝結構與欄位，及 OAuth2 Token endpoint。
- 在 Mac 以韌體相同 TWCA 信任根實際驗證 TDX TLS 端點；不使用略過憑證驗證的連線。
- 未帶憑證的 TDX 請求實際收到 HTTP 401。

- 完成 ESP32-S3 交叉編譯，離線預覽可旋轉並在新方向下切換北上／南下及翻頁。
- 使用者接回板子後，核對原 ESP32-S3 身分並寫入 app0，esptool 雜湊驗證通過；保留 NVS 與原分割表。開機診斷回報 0.1.2、螢幕方向與 CST816 觸控狀態。
